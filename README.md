# مملكة الرياضيات

«ابني مدينتك بذكائك»

مدينة تعليمية تفاعلية نستخدم فيها الرياضيات لبناء المرافق وحل مشكلات الحياة اليومية.
مشروع مدرسي لرياضيات الصف الرابع الابتدائي (الفصل الدراسي الأول)، يعمل موقعًا ثابتًا دون خادم أو قاعدة بيانات أو حسابات.

> المحتوى نطاق أولي قابل للتعديل، ولا يدّعي المطابقة الكاملة لطبعة محددة من كتاب الطالبة.

---

## ما الذي في الموقع؟

| المكان | الدرس |
|---|---|
| حي المنازل | القيمة المنزلية: بناء العدد، المنزلة والقيمة، القراءة والكتابة، الصور القياسية واللفظية والتحليلية |
| محطة الأعداد | المقارنة والترتيب |
| حديقة التقريب | التقريب إلى أقرب عشرة أو مئة أو ألف على خط أعداد |
| سوق المدينة | الجمع والطرح مع إعادة التجميع والطرح بوجود الأصفار |
| ورشة البناء | التقدير ومقارنته بالناتج الدقيق |
| مركز الإحصاء | قراءة الجدول والتمثيل بالأعمدة |
| ممشى الأنماط | الأنماط العددية والجمل العددية |
| مزرعة المدينة | الضرب بالصفوف والأعمدة والجمع المتكرر (قابلة للإخفاء) |

وفي كل حي: مثال تفاعلي قصير، ثم سؤال تدريب مع تلميح، ثم خمس مهمات مستقلة، ثم ختم ذهبي ونتيجة توضح المهارات المنجزة. عند العودة إلى حي مختوم تبدأ المهمات مباشرة.
ويوجد أيضًا: المرشدة «نُهى» التي تشرح وتعطي تلميحًا عند الضغط على «تلميح من نُهى» وتحتفل بالإنجاز، و«جواز مملكة الرياضيات الذهبي» (كتيّب يُفتح ويُقلَّب، فيه صفحة بيانات ورتبة في المدينة وأختام ذهبية مؤرخة وتأشيرات للمهارات)، والمهمة الختامية «افتتاح حديقة المدينة» التي تمنح الختم الكبير في الجواز. للجواز زر «تحميل» (صورة PNG) وزر «طباعة» (يمكن منه أيضًا الحفظ بصيغة PDF)، ووضع «جولة في مدينتي» للعرض أمام المعلمة.

يُحفظ التقدّم في المتصفح نفسه (localStorage)، فلا يحتاج الموقع إلى حساب أو بريد إلكتروني.

## ١. التثبيت والتشغيل محليًا

المتطلبات: **Node.js الإصدار 20.19 أو أحدث** (يُنصح بالإصدار 22). نزّليه من nodejs.org.

افتحي الطرفية (Terminal) داخل مجلد المشروع، ثم:

```bash
npm install
npm run dev
```

سيظهر رابط مثل `http://localhost:5173`؛ افتحيه في المتصفح.
لتجربته على الجوال أو الآيباد في الشبكة نفسها: `npm run dev -- --host` ثم افتحي العنوان الذي يظهر بجانب `Network`.

## ٢. بناء المشروع

```bash
npm run build      # يُنشئ مجلد dist الجاهز للنشر
npm run preview    # معاينة نسخة البناء محليًا
npm test           # اختبارات صحة المسائل والإجابات (اختياري)
```

## ٣. رفع الملفات إلى GitHub

**الطريقة الأسهل (من الموقع):**
1. ادخلي إلى github.com وأنشئي مستودعًا جديدًا (New repository)، مثلًا باسم `math-city`.
2. اختاري **uploading an existing file**، واسحبي محتويات مجلد المشروع **دون** مجلدي `node_modules` و`dist`.
3. اضغطي **Commit changes**.

**أو من الطرفية:**

```bash
git init
git add .
git commit -m "مدينة الرياضيات"
git branch -M main
git remote add origin https://github.com/اسم-المستخدم/math-city.git
git push -u origin main
```

ملف `.gitignore` يمنع رفع `node_modules` و`dist` تلقائيًا.

## ٤. النشر على Vercel

1. ادخلي إلى vercel.com وسجّلي الدخول بحساب GitHub.
2. اضغطي **Add New… → Project**، ثم اختاري مستودع `math-city` واضغطي **Import**.
3. تأكدي من الإعدادات (تُكتشف تلقائيًا، وهي مثبتة أيضًا في `vercel.json`):
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. اضغطي **Deploy**. بعد دقيقة تقريبًا يظهر رابط الموقع.

كل تعديل تدفعينه إلى GitHub يُنشر تلقائيًا من جديد.
يستخدم الموقع روابط بعلامة `#` (مثل `/#/passport`)، لذلك تعمل الروابط المباشرة وتحديث الصفحة دون أي إعداد إضافي.

## ٥. تعديل اسم الطالبة وبيانات المدرسة والمحتوى الدراسي

### بيانات الطالبة والمدرسة
من داخل الموقع نفسه: **الجواز ← بيانات المشروع**، أو من الشريحة الأولى في **جولة في مدينتي** (زر «تعديل البيانات»).
الحقول: اسم الطالبة، الصف، المدرسة، المعلمة. البيانات معبّأة مسبقًا من الإعدادات. ما يُكتب من داخل الموقع يُحفظ في الجهاز نفسه.

لتغيير البيانات التي تظهر تلقائيًا على كل جهاز، عدّليها في `src/config/settings.ts` داخل `defaultProjectInfo`:

```ts
export const defaultProjectInfo = {
  studentName: 'جمان فهد الردادي',
  grade: 'الرابع',
  school: 'ابتدائية سلمى بنت قيس',
  teacher: 'هند العنزي',
};
```

### اسم المدينة والجواز
في `src/config/settings.ts` داخل `branding`:

```ts
export const branding = {
  cityName: 'مملكة الرياضيات',
  cityKind: 'مدينة تعليمية تفاعلية',
  slogan: 'ابني مدينتك بذكائك',
  passportName: 'جواز مملكة الرياضيات الذهبي',
};
```

### الدروس ونطاق الأعداد وعدد المهمات
كل الإعدادات في ملف واحد: **`src/config/settings.ts`**

| الإعداد | ماذا يغيّر |
|---|---|
| `tasksPerDistrict` | عدد المهمات المستقلة في كل حي (الافتراضي ٥) |
| `guidedPerDistrict` | عدد أسئلة التدريب مع تلميح قبل المهمات (الافتراضي ١) |
| `suggestedPath` | ترتيب الأحياء في المسار المقترح |
| `houses.maxPlaces` / `houses.includeMillions` | أكبر منزلة (٦ = مئات الآلاف، أو تفعيل الملايين) |
| `station.min` / `station.max` / `trainCars` | نطاق أعداد المقارنة وعدد عربات الترتيب |
| `garden.roundTo` | منازل التقريب، مثل `[10, 100, 1000]` |
| `market.maxItemPrice` / `market.maxOperand` | أسعار السوق وحدود الجمع والطرح |
| `workshop.roundTo` / `min` / `max` | منازل التقدير ونطاق التكاليف |
| `stats.categories` / `scaleStep` / `maxVotes` | عدد المشاريع ومقياس الرسم |
| `walkway.steps` / `sentenceMax` | خطوات الأنماط وحدود الجمل العددية |
| `farm.enabled` / `maxFactor` | تفعيل الضرب وأكبر عامل |
| `hundredSpelling` | كتابة «مئة» أو «مائة» بحسب الكتاب |
| `columnSignSide` | موضع إشارة الجمع والطرح العمودي (`left` أو `right`) |

لإخفاء حي كامل: ضعي `enabled: false` في قسمه. تختفي مهماته من الخريطة والجواز، وتتكيف المهمة الختامية تلقائيًا.

إذا توفّر فهرس كتاب الطالبة، يكفي ضبط هذه القيم لتطابق الدروس وحدود الأعداد فيه.

### نصوص الأسئلة والأمثلة
- أسماء الأحياء والأمثلة التفاعلية وأسماء المهارات: `src/content/districts.ts`
- مولّدات الأسئلة (النصوص والتلميحات والشروح): `src/content/generators.ts`
- قصة المهمة الختامية: `src/content/session.ts`

بعد أي تعديل في المحتوى، شغّلي `npm test` للتأكد من سلامة المسائل.

## تنظيم الملفات

```
src/
  config/settings.ts      الإعدادات المركزية
  content/                بيانات الدروس ومولّدات الأسئلة (منفصلة عن الواجهة)
  lib/                    الأرقام العربية، الصيغة اللفظية، الرياضيات، الصوت، التوجيه
  state/progress.tsx      حفظ التقدّم واستعادته
  components/             الخريطة، نُهى، بطاقة السؤال، التمثيلات البصرية، أنشطة السحب والنقر
  screens/                الترحيب، المدينة، الحي، الجواز، المهمة الختامية، الجولة
  styles/app.css          الهوية البصرية والتجاوب
tests/content.test.ts     اختبارات صحة المسائل
```

## ملاحظات تقنية
- React + Vite + TypeScript، موقع ثابت بالكامل.
- الخطوط مضمّنة محليًا (IBM Plex Sans Arabic وBaloo Bhaijaan 2)، والرسومات كلها SVG داخل المشروع.
- تقبل حقول الإجابة الأرقام العربية والإنجليزية، وتعرض الأرقام دائمًا بالأرقام العربية.
- التعبيرات الرياضية تُعرض من اليمين إلى اليسار في خلايا مستقلة، وعلامة المقارنة مرسومة بحيث تتجه فتحتها نحو العدد الأكبر، فلا تنعكس دلالتها.
- كل نشاط سحب وإفلات له بديل بالنقر، والأنشطة تعمل باللمس والماوس ولوحة المفاتيح.
- المؤثرات الصوتية تُولَّد داخل المتصفح، ولا تعمل قبل تفاعل المستخدمة، ويمكن كتمها من زر الصوت.
- يحترم الموقع إعداد «تقليل الحركة» في الجهاز.
